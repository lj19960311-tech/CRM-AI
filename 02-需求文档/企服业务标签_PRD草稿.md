# 企服业务标签需求文档

**版本：V0.16｜更新：2026-11-04｜状态：规则探查稿。** 已确认要求与建议规则分开标注，未决项统一见第 7 节。

## 1 背景与范围

基于现有企业数据，对线索生成“企服”推荐标签，识别可能有工商财税、法律、知识产权等企服产品需求的企业，帮助销售及区域管理人员对接企服工作人员。标签不代表客户已确认需求。

| 项目 | 本期口径 |
| --- | --- |
| 数据范围 | 仅处理归属浙江、福建、广东、湖南区域公司的线索，按线索所属区域公司筛选，不按企业注册地筛选 |
| 本稿覆盖 | 工商财税标签、AI 品牌营销评分；法律、知识产权产品的具体商机规则仍待补充（Q-09） |
| 本期目的 | 先做规则探查，验证规则与数据是否可支撑评分；不预设已训练模型、自动采集能力或数据已接通 |
| 第一阶段 | 标签和评分结果均线下导出，字段与交接方式统一见第 5 节 |
| 后续阶段 | 将同一套推荐算法接入“万联有客”，在线索列表／详情展示“企服”标签；不作为本期交付 |

**本稿依据与状态：** 用户原始评分锚点、四区域范围、百分制公式、等级界线、十列导出及“连续一年都有招聘算持续招聘”为已确认口径。国标赛道映射、就绪度数量门槛及月份切分为本稿建议，确认后试跑；未覆盖情况保留 TBD。[客户评分 PRD](客户评分升级_PRD草稿.md)用于参考数据去重、时间和状态处理，不替代本需求的原始分值。

1. 金额分档取已公开的工商年报营业收入：≥300 万元命中“年开票≥300 万”，并叠加 R-05、R-06；＜300 万元命中“年开票＜300 万”。保留年份和“营业收入代理”来源说明，不表述为真实开票额，不据此生成“有开票需求”，不从 CRM 合同或订单反算。

## 3 AI 品牌营销评分（4.2）

### 3.1 计算顺序

对第1节范围内的关联企业依次执行：**赛道筛选 → 就绪度 J → AI 紧迫度 U → 百分制总分 P／等级**。未注册自然人缺少企业依据时待判定。数据见第4节，导出见第5节。

### 3.2 赛道适配 F

| 分数 | 赛道 | 处理 |
| --- | --- | --- |
| 20 | 软件、工业、新材料、法律财税 | 进入候选池 |
| 15 | 高端旅游、定制家居、汽车 | 进入候选池 |
| 0 | 快消、视觉主导品类 | 退出 |

工商国标为主、经营范围为辅，代码明细见**附录A**（建议映射，Q-07）。取最细有效层级，不能由粗码反推细码；具体赛道优先于一般工业，只计一次分，不凭任意经营关键词改档。高端／定制／快消／视觉主导证据不足且影响分档时，不回退工业20分。行业证据不足或冲突→待判定；已核实不属任何已列赛道→一票否决退出。代码清单尚未补全不等于未命中；不按制造业、规模或国企／外资身份单独否决。退出或赛道待判定均停止后续评分。

### 3.3 就绪度 J

**原分值不变；数量与窗口细则为试跑建议（Q-11），持续招聘一年已确认。** 所有数量先核验覆盖并去重，来源见第4.3节。

| 指标 | 高档 | 中档 | 低档 |
| --- | --- | --- | --- |
| 内容资产 | **10**：专利／商标／软著近24个月的前后两个12个月各新增≥1项 | **6**：有存量，近24个月无新增 | **2**：三类均核实无记录 |
| 资质与权威信源 | **8**：有效、可核验引用的独立许可／资质／信用评级记录≥2项 | **4**：1项 | **0**：核实无有效记录 |
| 经营活跃度 | **10**：近12个月招投标≥3条，且连续一年招聘 | **6**：正常经营、最近应报年报已报，且已排除10分和2分条件 | **2**：核实停业／歇业，或最近连续两个已到期的应报年度均未报 |
| 风险负向项 | **0**：本项来源完整核验，确认无纳入风险 | **−5**：有已核实为轻微的司法／处罚，无其他未明风险，且未命中−15 | **−15**：当前有效的被执行／股权冻结事项去重合计≥2条 |

连续一年招聘＝连续12个月每月至少1条招聘记录；建议取评分月之前12个完整自然月，不设岗位／人数门槛。其他12／24个月窗口按评分日回溯。每项取一档，风险先判−15、再−5、再0；冲突待核验。近两年新增但不连续、单条执行／冻结或非轻微司法／处罚，未命中已定义档位时均待判定，不默认给中档。

### 3.4 AI 紧迫度 U

| 指标 | 评分锚点 |
| --- | --- |
| 品牌 AI 缺失 | **10**：品类核心问题下完全未出现；**6**：偶尔出现、排名靠后；**0**：稳定入选推荐 |
| 竞品占位 | **10**：高频占据选型类回答；**6**：偶现；**0**：无明显占位 |
| 信息错误／参数虚构 | **8**：参数／资质被说错；**4**：过时或不完整；**0**：准确 |
| 引用来源缺失 | **7**：品牌内容无权威信源可引；**3**：部分有来源；**0**：信源充分 |

基于固定问题池的多平台回答评分，输入与网站见第4.4节；“高频／偶尔／稳定／充分”等阈值仍待Q-13确认。

### 3.5 总分、等级与缺失处理

```text
J = 内容资产分 + 资质信源分 + 经营活跃度分 + 风险负向分
U = 四项 AI 紧迫度得分之和
T = F + J + U
P = T ÷ 83 × 100
```

83＝20＋28＋35；赛道标称上限30不参与分母。不额外加权，J保留−11～28的原值，风险只扣一次。P是评分而非购买概率；按未四舍五入值分级，展示可保留两位小数。

| 等级 | P范围 | 跟进方向 |
| --- | --- | --- |
| S | 80≤P≤100 | 优先联系；J达标后对接AI品牌营销 |
| A | 60≤P＜80 | 延缓触达，时长TBD |
| B | 40≤P＜60 | 按服务建议对接 |
| C | P＜40 | 观察池 |

**服务建议：** J＜15→先补内容基础；J≥15→达到服务门槛。等级只决定优先级，J＜15不直接定B，即使S/A也先补基础；风险导致低分须说明风险原因，不能推断内容不足。完整总分均需AI诊断，J＜15也不例外。

| 情况 | 处理 |
| --- | --- |
| 缺数据、未公开、未核实 | 待判定，不补0、不缩分母、不默认C；仅用原档位，不插值 |
| 规则未覆盖 | 待判定，不能直接套全范围；只有可能档位集合明确时才允许算区间 |
| 风险未核验／整组AI诊断无有效分／赛道未定或退出 | 不输出最终等级；赛道未定或退出不算总分 |
| 赛道通过、风险已核验、AI已有有效分，其余有缺项 | 已知分须有证据且档位确定；按可能的原档位算总分上下界。同一等级内可定级并保留分数区间，跨级则等级待定 |
| J为区间 | 上界＜15→先补基础；下界≥15→达标；跨15→服务建议待定 |
